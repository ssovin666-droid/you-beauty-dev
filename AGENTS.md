# Правила проекта

- Источник обновления Cosmi Star: ZIP you-beauty-dev-cosmi-star (1).zip, перенесённый в этот репозиторий.
- Капсула и анимация открытия существа: design-reference/character/Cosmi Capsule (перенесено в StarScene, режим capsule).
- Тестовый и рабочий запуск используют общий код, но отдельные процессы, базы, Telegram-ботов и адреса.
- В тестовой среде Amplitude полностью отключён, включая identify, autocapture и session replay. Не удалять события из кода ради тестового запуска.
- Каждая новая пользовательская функция должна включать явные события аналитики и обновление docs/analytics.md: действие, успешный результат, ошибка при необходимости, свойства события.
- Нажатие не означает успешное выполнение. Серверные результаты фиксировать после успешного сохранения. Не дублировать одно событие на клиенте и сервере.
- Перед релизом проверить production-флаги аналитики и ключи на frontend, API и процессе бота по docs/testing-release.md. VITE_* применяются при сборке.
- Не отправлять токены, initData, фото и персональные тексты в свойства событий.
